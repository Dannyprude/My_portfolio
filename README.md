 # Personal Portfolio Website

A fast, responsive, and visually engaging personal portfolio website built with modern HTML5 and advanced CSS3 styling featuring animated gradients, glassmorphism effects, and smooth hover-interactive elements.

## Features

* **Lively Animated Hero Section:** Dynamic background gradients and a glowing, interactive profile display.
* **Modern UI Components:** Glassmorphism navigation bar, smooth card elevation on hover, and custom badge pops.
* **Fully Responsive Grid:** Automatically adapts cleanly to mobile devices, tablets, and desktop displays.
* **Lightweight Local Setup:** Easily hosted and tested locally via Python and exposed to the public via Cloudflare Tunnels.

## Tech Stack

* **HTML5**
* **CSS3** (Flexbox, CSS Grid, Custom Animations, Backdrop Filters)
* **Python** (`http.server` for local hosting)
* **Cloudflare Tunnel (`cloudflared`)** for public web tunneling
